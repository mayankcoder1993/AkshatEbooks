## 1. Executive Summary & Root Cause Analysis

While the technical assertions (47/47 passing) and Newman execution pipelines are mathematically sound, a sharp gap has emerged between the **visual graphic novel presentation layer**, the **comic art style consistency**, and the **pedagogical flow of hands-on student missions**.

The user screenshot of **Beat 1 vs Beat 2** in Chapter 01 exposed four critical systemic gaps:
1. **Art Style Fracture:** Beat 1 is a painterly, cross-hatched, richly shaded gouache illustration (the leaking brass bottle), while Beat 2 is a flat 2D vector cartoon with minimal shading. Placing them side by side breaks reader immersion.
2. **Dialogue Ceiling & Headroom Collision:** The SVG speech balloon overlay was positioned rigidly with CSS percentage offsets, placing text boxes directly across Akshay's forehead and facial expressions.
3. **Card Clutter / Internal Prompt Bleed:** The card footer displayed duplicate information: a caption, an uppercase `SCENE & ACTION` storyboard summary, and a `CORE WIRE LESSON` box. This feels like an internal prompt evaluation sheet rather than a finished book.
4. **Tooling & Hover Disruption:** An intrusive browser `title` tooltip persisted when the mouse lingered between cards.
