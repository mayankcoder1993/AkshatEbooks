# Chapter 01: Image AI Prompts & Asset Catalog

## Visual Style Guide
- **Art Style:** Authentic Madhubani (Mithila) folk art graphic novel style with double-line black ink contours, sharp almond eyes, and rich flat color fills.
- **Border:** Intricate ornamental peacock, fish, and lotus floral border frame.
- **Aspect Ratio:** 16:9 widescreen format (`1365x768` or `1408x768`).
- **Background:** Clean pure white (`#FFFFFF`) or sun-bleached ivory (`#F8FAFC`).
- **Rule:** Strictly characters and setting; no mock code editors or fake IDE screens inside the illustration.
