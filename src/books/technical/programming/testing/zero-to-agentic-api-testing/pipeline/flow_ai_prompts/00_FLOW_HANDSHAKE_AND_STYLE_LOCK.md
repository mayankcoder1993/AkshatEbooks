## 1. THE FIVE INVIOLABLE PRODUCTION LAWS

Every single prompt dispatched to Flow AI must obey these five foundational laws:

### Law 1: Standalone Single Canvas Geometry (NO MOSAICS OR GRIDS)
- **Aspect Ratio:** Strictly Full Bleed 16:9 (`--ar 16:9`).
- **Edge to Edge Composition:** The image must fill the entire canvas from border to border.
- **Strictly Borderless:** Absolutely no picture frames, white borders, ornamental folk borders, margins, or divider lines.
- **Single Continuous Scene:** NEVER render a 4 panel comic strip, split screen mosaic, or collage inside one single image file. Every prompt describes ONE single dramatic moment in one unified space.

### Law 2: Zero Text, Speech Bubbles, or In Image Lettering
- **Zero In Raster Dialogue:** NEVER burn speech bubbles, thought clouds, dialogue balloons, caption boxes, subtitles, or character name placards into the image.
- **Zero Graphic Lettering:** All dialogue, technical explanation cards, and speaker avatars are injected dynamically by React and SVG code layers in the web and print engines above the image.
- **Screen Typography Realism:** Computer displays must show authentic code syntax or clean UI bars, never gibberish runes, cartoon doodles, or English paragraphs.

### Law 3: Headroom Ceiling Law (Top 25% to 30% Negative Space)
- **Dialogue Space Invariant:** The **top 25% to 30% of EVERY canvas must remain clean negative space**.
- **Approved Negative Space:** Vaulted sandstone arches, acoustic wood ceiling beams, soft amber atmospheric wall gradients, soft shadow, or evening monsoon sky visible through stone lattice screens.
- **Clearance:** Character heads, hands, laptop displays, and key focal objects must NEVER intrude into the top 30% zone. This space is strictly reserved for reader facing glassmorphism speech cards.

### Law 4: Visual Theme Continuity (Old Heritage Sandstone and Modern Gadgets)
- **Setting Architecture:** 300 year old carved Indian red and beige sandstone architecture seamlessly fused with modern high performance computing gear.
- **Environmental Elements:** Dravidian stone pillars, carved geometric jali screens, vaulted arches, massive polished teak desks, warm 2700K brass gooseneck task lamps contrasting with cool 6500K glowing terminal screens and dark server racks.
- **No Folk Art on Technology:** Laptops, servers, and code editors must look like authentic, sleek, industrial developer equipment. Absolutely NO tribal motifs, ethnic patterns, or fantasy decorations on computers!

### Law 5: Separation of Narrative Comic Art and Application Interface Screens
- **Track A (Narrative Comic Panels):** Follows the story of Akshay, Sameer, Mrs. Iyer, Ananya, and Ramu inside the heritage campus.
- **Track B (Application Interface Screens):** Completely clean, photorealistic developer workbench screens with **ZERO heritage theme and ZERO decorative fluff**.
  - Built using a structured step by step breakdown:
    - **Chunk 1:** Input, Processing (Under the Hood), and Output.
    - **Chunk 2:** Input, Processing (Under the Hood), and Output.
    - **Consolidated Summary:** Overall program Input, Processing, and Output.

## 4. PROMPT FORMULA FOR ALL NARRATIVE BEATS

Every narrative scene prompt must follow this exact four segment anatomy:

```text
[Camera Framing & Aspect Ratio] + 
[Character Action & Emotional Beat with Hard-Locked Clothing and Props] + 
[Architectural Sandstone Environment with Ambient Lighting] + 
[Mandatory Headroom Instruction: Top 28% clean negative space] + 
[Engine Flag: --ar 16:9]
```

### Critical Rules for Prompt Writers:
1. **Never write dialogue lines in the prompt:** Do NOT write `Akshay says "Where is the route parameter?"`. This guarantees that Flow AI will render text and speech bubbles. Instead write: `Akshay points at line 14 of the code editor with an intense expression of forensic realization`.
2. **Never change character clothing mid mission:** Akshay stays in his white kurta; Sameer stays in his peacock indigo kurta; Mrs. Iyer stays in her amber saree.
3. **Always preserve the top 28% ceiling:** Explicitly describe the ceiling as vaulted stone arches, amber gradients, or soft shadow.
