# Global Programming & API Testing Directives

## 1. Pedagogical Philosophy
- **Real-World Engineering Over Flat Analogies**: Never use generic analogies as substitutes for actual technical mechanics. Always explain the real software engineering reality:
  - Heterogeneous tech stacks (Swift on iOS, Kotlin on Android, React/TS on Web, Python/FastAPI or Java/Spring Boot on Backend).
  - Cross-platform communication via universal transport (HTTP) and standard data serialization formats (JSON, XML, Protobuf).
  - Security, credentials separation, process isolation, rate limiting, and database connection pooling.
- **Graphic Novel Pacing & Emotional Arc**:
  - Protagonist (Akshay) is an apprentice QA engineer who experiences authentic production pain points (e.g. Results day portal meltdown).
  - Mentor (Sameer) provides Socratic, first-principles guidance.
  - Motivation: Akshay vows to build a modern, high-performance web app for his college to solve the problem, learning step-by-step from Sameer.
- **Line-by-Line Code Unboxing**:
  - Never dump large code blocks at once.
  - Break code down line-by-line or 2-line chunks: state what the line does, why it is necessary, what happens if omitted, and ask the reader to predict the output.
- **Zero Copyrighted Tool Names**:
  - Never use commercial trademarks like Postman or Insomnia. Always refer to it as the API Testing Workbench or The Wire Inspector.

## 2. Visual Layout Directives
- **Speech Balloons Over Art**: Dialogue clouds must float naturally at the top and sides of scene illustrations.
- **No Mechanical Panel Labels**: Do not display rigid PANEL badges. Present continuous narrative flow with context and timestamps.
- **Embedded Prompt Metadata**: Every scene block must include structured promptMeta (positive prompt, negative prompt, aspect ratio, target asset path) in Madhubani Mithila Folk Art graphic novel style.

## 3. Autonomous AI Research Protocol
- When deep-dive research is needed, record the research request in artifacts/RESEARCH_PROMPTS.md with explicit task instructions, expected output schemas, and target output paths for autonomous sub-agents.
