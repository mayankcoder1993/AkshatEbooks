# Book 4 Syllabus Matrix: Autonomous Agentic Systems

**Book Title:** *Autonomous Agentic Systems: Building & Testing AI Swarms*  
**Subtitle:** *LangGraph, CrewAI, MCP, and Guardrails for Production-Grade Multi-Agent Systems*  
**Target Repository Path:** `src/books/technical/programming/ai-systems/autonomous-agentic-swarms/`  
**Deliverable Project:** The Sentinel Swarm: An autonomous, budget-capped, sandboxed API quality & regression testing multi-agent swarm that ingests OpenAPI specs, runs Newman test suites, diagnoses 500 errors, and files verified GitHub issues without human babysitting.

---

## 1. Complete 12-Chapter Syllabus Matrix

| Chapter | Title & Subtitle (Rule 19 Compliant) | Core First-Principles Gotcha & Mechanical Vulnerability | Narrative Crisis, Emotional Arc & Cast | Hands-on Lab & Interactive Bench |
| :--- | :--- | :--- | :--- | :--- |
| **Ch 01** | **The Agentic Anatomy:** From Single Prompts to Autonomous Tool Loops | The ReAct (Reason + Act) loop, tool call serialization, token inference latency, and the illusion of agentic intent. | *The 03:00 AM Prompt Wall:* Akshay prompts an LLM to debug a network issue; it outputs plausible explanations but cannot ping the server; Akanksha introduces tool binding. | ReAct engine visualizer tracing raw prompt tokens into JSON tool invocations. |
| **Ch 02** | **Structured Outputs with PydanticAI:** Eliminating Output Hallucinations | Schema validation on agent outputs, handling malformed JSON from LLMs, self-healing parse loops, and strict type constraints. | *The Broken Webhook Disaster:* An agent returns Markdown backticks inside a JSON string, crashing the payment webhook; Devansh enforces strict Pydantic models. | PydanticAI schema workbench with automatic schema repair and retry loops. |
| **Ch 03** | **LangGraph Stateful Cyclic Graphs:** Durable Checkpointing and State Machines | `StateGraph`, nodes, edges, conditional dispatch, state schema definitions, and durable checkpointing with SQLite/Postgres. | *The Friday Afternoon State Amnesia:* A multi-step code review agent crashes mid-turn; all context is lost; Sameer introduces cyclic graphs and persistent checkpointing. | LangGraph state graph visualizer with time-travel inspection and replay capabilities. |
| **Ch 04** | **The Infinite Loop Autopsy:** Token Budgets and Circuit Breakers | Unbounded tool recursion loops, runaway API billing, token counting decorators, and hard iteration thresholds (`max_iterations=10`). | *The $4,127 Overnight Disaster:* Akanksha's research agent runs 847 repetitive search turns while the team sleeps; Varun installs token rate-limiters and kill switches. | Circuit breaker workbench demonstrating budget caps and emergency kill triggers. |
| **Ch 05** | **Human in the Loop Approvals:** Gating Destructive Tool Calls | `interrupt_before`, paused execution states, resume payloads, approval workflows for database mutations, and audit logging. | *The Accidental Drop Table Incident:* Mirroring the 2025 Replit crisis, an agent executes an unreviewed SQL script; Akshay halts it at the human approval gate. | Interactive Human-in-the-Loop approval console reviewing staged SQL mutations. |
| **Ch 06** | **CrewAI and Role Based Swarms:** Hierarchical and Sequential Orchestration | Defining Crews, Agents, Tasks, and Tools; delegation protocols; manager-worker hierarchies; and inter-agent communication overhead. | *The Chaos Meeting:* Three uncoordinated agents overwrite each other's summaries; Akanksha configures a Manager agent to delegate work sequentially. | CrewAI task delegation tree showing role boundaries and task handoffs. |
| **Ch 07** | **The Model Context Protocol:** Building Custom stdio and SSE Tool Servers | MCP architecture, JSON-RPC 2.0 message framing, stdio vs Server-Sent Events (SSE) transports, dynamic tool discovery, and client-server decoupling. | *The Vendor Lock-in Crisis:* The team faces proprietary agent APIs; Sameer transitions their custom diagnostic scripts into universal MCP tool servers. | Building a local Python MCP server exposing safe ping and status inspection tools. |
| **Ch 08** | **MCP Security and Sandboxing:** Preventing Filesystem and Secret Exfiltration | Path traversal vulnerabilities (`../../.env`), chroot jail environments, Docker sandbox execution, and read-only mounts. | *The Leaked Secret Audit:* Devansh prompts an agent to read files, which retrieves the production `.env`; Devansh and Akshay sandbox MCP tool boundaries. | MCP security sandbox testing path traversal injection attempts. |
| **Ch 09** | **Prompt Injection Defense:** Defending Against Indirect Hostile Payloads | OWASP LLM Top 10, indirect prompt injection via crawled web pages and API responses, NeMo Guardrails, and Colang flows. | *The Poisoned Issue Ticket:* A malicious user submits a GitHub issue instructing the agent to ignore rules; NeMo Guardrails intercept and quarantine the payload. | NeMo Guardrail testing workbench simulating indirect prompt injection attacks. |
| **Ch 10** | **PII Redaction and Data Guardrails:** Protecting Sensitive Corporate Data | Regulatory compliance, automated regex masking, named entity recognition (NER) redactors, and sanitizing prompt payloads before transmission. | *The Compliance Threat:* Student phone numbers and admit card IDs are sent to external LLMs; Swati and Akshay build pre-transmission redaction filters. | Pre-flight redaction pipeline scrubbing sensitive data before LLM dispatch. |
| **Ch 11** | **Agent Observability and Tracing:** Profiling Multi Turn Swarms in Production | OpenTelemetry standards, LangSmith/LangFuse distributed traces, tracking latency bottlenecks, token consumption attribution, and cost monitoring. | *The Latency Spike Investigation:* An agent takes 48 seconds to respond; Akshay inspects distributed trace waterfalls, discovering a redundant 4-turn search loop. | Distributed trace waterfall showing exact latency and token consumption per node. |
| **Ch 12** | **Capstone: The Sentinel Swarm:** The Autonomous Production QA Watchdog | Multi-agent coordination: Spec Ingestion Agent, Test Generator, Newman Execution Runner, Bug Diagnoser, and GitHub Issue Author. | *The Autonomous Release Gate:* The complete Sentinel Swarm autonomously audits the Book 2 Student Task API under $0.50 budget, catching 3 regressions before launch! | Live Sentinel Swarm running in GitHub Actions with Newman verification. |
