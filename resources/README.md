## 📌 Strict Editorial Rules Followed Across All Files
1. **Rule 19 (Zero Hyphens or Dashes in Titles/Headings):** All chapter titles, section headers, and subheadings strictly use colons, commas, bullets (`•`), or parentheses.
2. **Text-Free Comic Artwork:** Panels describe pure visual composition; dialogues are tagged with clean speaker IDs (`[1] AKSHAY:`, `[2] PALASH:`, `[3] SAMEER:`).
3. **Pure Data Content Blocks:** All code, quizzes, and workbenches are structured for automatic compilation into Web View, static PDF/Book View, and native editable Word (`.docx`).
