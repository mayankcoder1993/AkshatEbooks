## 1. THE ANTI "VIBE-CODING" DOCTRINE & PEDAGOGICAL LADDER

### The 2025–2026 Industry Crisis
The proliferation of generative AI coding assistants (ChatGPT, Claude, Cursor, Copilot) has created a hazardous talent distortion: **"vibe coders."** Developers can prompt high-level web services into existence, but have **zero understanding of the physical memory, socket states, byte streams, and failure mechanisms** operating beneath the glass. When production incidents, silent data corruption, or memory leaks occur, they are helpless.

### The 3-Tier Pedagogical Ladder
1. **Tier 1: Direct Technical First (Clean Concepts):** If a concept is intuitive in standard technical language, state it directly and mathematically. No unnecessary metaphors.
2. **Tier 2: Physical & Visual Metaphors (For Invisible Machine Behavior):** When teaching invisible computing mechanisms (RAM pointers, TCP byte streams, event loop selectors, bytecode stack), ground them in tangible, physical realities (cutting chai carriers, restaurant order slips, brass thali platters, garden hose water chunks).
3. **Tier 3: The 7-Layer Forensic Audit Protocol:** Every AI-generated codebase is subjected to a 7-stage interrogation before touching production:
   - *Layer 1: Secrets & Exposure* (`gitleaks`, `.env` exfiltration)
   - *Layer 2: Git Hygiene & History* (purging credentials, bisecting silent bugs)
   - *Layer 3: Dependency Integrity* (`pip-audit`, hallucinated package detection)
   - *Layer 4: Concurrency & Runtime* (sync calls blocking async loops, socket leaks)
   - *Layer 5: Input Boundaries & Security* (strict Pydantic schemas, SQL injection, CORS)
   - *Layer 6: Error Contracts & Observability* (scrubbing production stack traces, structured logs)
   - *Layer 7: AI Hallucination Traps* (dead imports, deprecated APIs from stale training sets)
