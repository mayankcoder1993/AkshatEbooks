## PART A: SUBJECT INVARIANTS

### A1: What Must Be Taught

FOUNDATIONAL LAYER:
  Intuition before abstraction: every mathematical concept must begin
    with a concrete geometric, physical, or numerical representation.
  Number systems and algebraic reasoning: sets, functions, equations,
    identities, and structural relationships.
  Descriptive statistics: measures of central tendency (mean, median, mode),
    dispersion (variance, standard deviation, IQR), distributions.
  Probability fundamentals: sample spaces, conditional probability,
    Bayes' theorem, independent vs mutually exclusive events.

PRACTICAL LAYER:
  Step-by-step derivation: every formula must be derived or motivated,
    never presented as an unproven decree.
  Geometric interpretation: graphs, coordinate geometry, transformations,
    and area under curves.
  Statistical inference: hypothesis testing, p-values, confidence intervals,
    Type I and Type II errors, normal and binomial distributions.
  Computational execution: verifying mathematical computations via
    clean algorithmic steps or code validation.

PROFESSIONAL / APPLIED LAYER:
  Linear algebra foundations: vectors, matrices, determinants,
    eigenvalues/eigenvectors, dimensional transformations.
  Multivariable calculus intuition: gradients, partial derivatives,
    optimization surfaces, saddle points.
  Machine learning connections: loss functions, gradient descent,
    linear regression, probabilistic modeling.
  Error analysis and boundary testing: asymptotic notation, edge cases,
    numerical stability, catastrophic cancellation.

### A2: Proof System

Zero unverified mathematical assertions:
  Every algebraic manipulation must show all intermediate steps.
  Every geometric claim must correspond to a verified SVG coordinate illustration.
  Every statistical theorem must be demonstrated with empirical or synthetic data.
  Formulas must include variable domain restrictions (e.g. x != 0, n >= 1).

### A3: Interactive Element Types

Function Grapher Workbench (math-graph.svg.js):
  Interactive Cartesian plane with labeled axes, function curves,
  roots, tangent lines, inflection points, and shaded integral areas.

Statistical Distribution Workbench:
  Normal curve, bell shape with standard deviation bands (+/- 1 sigma, 2 sigma),
  shaded rejection regions (alpha), critical values.

Step-by-Step Derivation Card:
  Standardized 4-part visual card:
    1. Starting Equation / Premise
    2. Algebraic Transformation / Principle Applied
    3. Intermediate Simplified State
    4. Final General Formula and Domain Constraints

Geometric Proof Canvas:
  Geometric visual dissection proving theorems (e.g. Pythagorean theorem,
  binomial expansion via geometric squares/cubes).
